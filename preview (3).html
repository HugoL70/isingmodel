Spatial coherence controls whether different emitters share the same radiation history. Temporal coherence controls whether that radiation is a continuous sine wave or the existing random thermal packet stream.

Spatial OFF + Temporal OFF = fully incoherent packet streams.
Spatial ON + Temporal OFF = shared random packet stream.
Spatial OFF + Temporal ON = independent continuous sine waves.
Spatial ON + Temporal ON = the same continuous sine wave from every source.

The displayed field is Etotal = Σ Ei at every retained simulation pixel.

Red = positive field, blue = negative field, white = zero in the main field plot. The thin strip below is not a separate detector model: it simply samples the colours immediately on the absorbing screen and redraws them with a small height. The black detector dots show one central detector and five equally spaced detectors on each side.

For the correlation calculation, intensity is I = E². The plotted quantity is the cumulative, time-weighted normalized fluctuation correlation C(Δy) from the start of the current measurement. Nothing is propagated past the screen.

Performance optimizations preserve the same simulation grid and physics: the full 2D field is rendered in parallel with WebGL2 on the GPU, while the CPU evaluates only the screen strip and detector points needed for the statistics. A CPU fallback is retained for browsers without WebGL2.
